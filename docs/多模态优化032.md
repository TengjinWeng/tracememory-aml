视觉/OCR 固定用 Codex CLI `gpt-5.6-sol`，向量固定用本地 Qwen3-Embedding-0.6B。

## 修改与原因

上一版的 CLI 已正确描述图片，检索却丢掉了对象关系的顺序；统一的新近度也会偏向无关的新上传。
本轮增加 `AlgorithmStore`，保留独立的有序来源描述、OCR 和事实，只用于检索排序：

- 对齐“对象—方向—对象”，支持左右、上下与反向表达；结合明确的绝对位置。
- 处理常见颜色别名，避免把不同颜色的对象随意替换成同一个裸名词。
- 否定或不确定描述不作为肯定的关系证据，无法识别时保留原有检索分数。
- 时间偏好限定到同一实体与住址、工作、偏好或会议属性，避免新收据覆盖住址更新。
- 历史状态查询采用来源时间截点；支持 ISO/中文日期和英文完整月份。
- 比较、前后区间等复杂问题不强加这一时间偏好。
- 修复中文实体边界把“现在”并入人名的错误。

有序证据按完整 user_id 保存；重建仅允许 dev: 自建作用域。新的辅助表与来源一同清理。
细化排序只读取原始候选中前 128 条的辅助证据，避免每次装载整个用户的长文描述。
Search 继续返回原始图文来源，不返回生成答案。

这两组均为已知自建诊断，包含用于调试的样例，不能当成独立泛化评测、官方成绩或冷启动速度。

时间选择依赖来源时间戳，日期截点按 UTC 解释，不等于已经抽取出所有事件实际发生时间或时区语境。
