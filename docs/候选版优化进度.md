# v0.2 候选版优化进度

原始审核版本：0.1.0-protocol，服务器端口 18086，继续保持原接口。
候选版：0.2.0-candidate，独立端口 18087、data-candidate 数据库、独立服务密钥。
候选版目前只在服务器内网回环地址运行，未切换公网评测地址，模型调用默认关闭。

## 已实现的算法工作

1. 像素指纹：解码并统一 EXIF 方向与 RGBA，解决像素相同但 PNG 编码不同的问题。
   原始图片作为证据保留；它不是学习到的视觉语义，不能凭它理解新图片。
2. 检索融合：BM25 与可选的 text-embedding-v4 分块向量采用 RRF 融合。
3. 二跳扩展：从首轮来源证据提取低频实体，在相同 user_id 内补充其他会话证据。
4. 时序偏好：只对“现在/最新”等查询按来源时间加权，属于启发式，不是完整冲突治理。
5. 图片预算：默认最多 4 张、2 MiB 解码图片，并去除重复像素图片；原库不变。
   超出预算的图片可能被省略，尚需真实任务评估信息损失。
6. 指定模型适配：gpt-4o-mini 输出视觉/OCR/事实索引，text-embedding-v4 分块向量。
   已知图片的纯图查询复用像素匹配，避免额外模型请求。
7. 成本与隐私：每用户缓存、持久化调用次数上限、不自动重试、不替换模型、错误不泄露密钥。
8. 失败恢复：原始写入后如索引失败，不返回成功，也不让 Search 看到未完成索引的记录。

## 已验证与没有验证的界限

使用同样的 7 个已知自建合成问题，离线候选版：

| 指标 | 原基线 | 离线候选 |
| --- | ---: | ---: |
| 首位命中 | 3/7 | 5/7 |
| 前五位命中 | 4/7 | 6/7 |
| 两条跨会话证据都进前五 | 否 | 是 |

这组样例已用于诊断和开发，不是独立泛化测试，也不是比赛成绩。
同义改写用例仍未解决，需真实 Embedding 测试；尚未验证真正的视觉描述/OCR效果。
真实模型 API 没有调用，开发没有产生模型费用。Provider 测试使用明确的模拟响应。

候选测试覆盖 HTTP 图文回传、重新编码、二跳、时间、跨用户隔离、幂等、索引失败恢复、
向量融合、Embedding 批次与维度、模型响应检查、缓存与跨进程持久化费用计数。
原协议版的 20 项测试仍通过。原始对比结果：`candidate-comparison.json`。
