# 正式模型调用核对

核对日期：2026-10-29。开发继续用 Codex CLI `gpt-5.6-sol` 和本地 Qwen3-Embedding-0.6B；本文不要求现在充值，也没有发起供应商请求。

## 比赛平台负责什么

平台运行并承担 Answer、Eval 和评测编排；我们部署并承担自身 Add/Search、存储和网络。
主办方发放的 Eval Key 用于启动评测和查看私有结果；Memory System Key 用于访问我们的接口。
不需要向主办方提交 OpenAI/百炼模型凭证。

公开规则未找到给参赛系统发放模型代理地址、模型服务凭证或免费额度的承诺。
因此不能把 Eval Key 当成模型服务 Key，也不能断言模型调用只能由用户购买。
以下是供应商公开支持的调用路径；本账户的模型权限、可达性和余额尚未实测。

来源：[参赛说明](https://agentmemoryleaderboard.ai/rules)、[赛事 FAQ 01/05](https://agentmemoryleaderboard.ai/competition/)、[官方仓库](https://github.com/AML-memory/agent-memory-leaderboard)。

## gpt-4o-mini

- 官方入口：`POST https://api.openai.com/v1/chat/completions`。
- 认证：`Authorization: Bearer <模型服务凭证>`；在我们服务器内使用，不交给评测平台。
- 模型：`gpt-4o-mini`，支持文本和图片输入；图片可使用 Base64 data URL。
- 请求体使用 `messages`，图像作为 `image_url` 内容项；JSON 抽取设置 `response_format: {"type":"json_object"}`。
- 本项目适配器已经实现该路径、响应校验和持久化调用上限，不自动替换型号。
- 官方已标记弃用，公告停止日期为 2027-01-14。当前文档仍列接口能力；是否能调用须由真实账户验证，不能由文档推定。

来源：[模型页](https://developers.openai.com/api/docs/models/gpt-4o-mini)、[图片输入](https://developers.openai.com/api/docs/guides/images-vision?api-mode=chat)、[停用时间表](https://developers.openai.com/api/docs/deprecations)。

当前 OpenAI 另有符合条件的 ChatGPT Pro/Business 订阅领取 API 赠额的官方方案，
需账号所有者将订阅与自己拥有的 API 组织关联。它不等于 CLI 登录缓存自动成为 API 凭证；
本任务未核实该账号资格或领取情况，也未执行关联或充值。
来源：[ChatGPT 订阅 API 赠额](https://developers.openai.com/api/docs/guides/chatgpt-api-credits)。

## text-embedding-v4

- 供应商：阿里云百炼。不是本地 Qwen3-Embedding 权重的另一个名称。
- 当前北京文档的 OpenAI 兼容入口：
  `POST https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1/embeddings`。
- `{WorkspaceId}` 必须替换为控制台真实业务空间；地域、地址和模型服务凭证需匹配。
- 模型：`text-embedding-v4`；本项目选 1024 维，使用 `encoding_format: "float"`。
- 每批最多 10 条，每条最多 8192 Token。本项目采用更小的文本窗口和每批最多 10 条。
- OpenAI 兼容接口与 DashScope 原生接口的参数不能混用；原生检索区分使用 `parameters.text_type`，兼容适配器不擅自加入该参数。

来源：[模型信息](https://help.aliyun.com/zh/model-studio/text-embedding-v4)、[同步接口与地址](https://help.aliyun.com/zh/model-studio/text-embedding-synchronous-api/)。

## 已准备的配置和验证

私密文件 `secrets/model-apis.env` 支持 `OPENAI_BASE_URL`、`OPENAI_API_KEY`、
`DASHSCOPE_BASE_URL`、`DASHSCOPE_API_KEY`。留空时不请求；模型凭证与 AML Key 分开。

`python scripts/check_model_apis.py` 仅检查字段。
将来在调用渠道和费用授权具备后，显式加 `--call` 才做一张自制图和一条文本的验证。
文档核对、请求结构单元测试、真实供应商可用性、官方 Smoke、Full 分别记录，不互相替代。

当前提交的 `0.3.1-protocol` 是无模型的协议配置，只用于版本绑定和 Smoke；
不把 CLI/Qwen 开发模型用于这个学术榜版本，也不将其 Smoke 结果算作完整算法版验证。
